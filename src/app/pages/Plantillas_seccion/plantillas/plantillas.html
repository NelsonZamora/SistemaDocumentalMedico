📄 Subir Plantilla Word

Cree plantillas dinámicas para generar documentos automáticamente.

¿Cómo funciona?
1️⃣ Suba el documento
Seleccione un archivo Word (.docx)
2️⃣ Analice la plantilla
El sistema detectará automáticamente los campos.
3️⃣ Configure los campos
Seleccione si son campos libres o datos de la base.
4️⃣ Guarde la plantilla
La plantilla quedará lista para generar documentos.
Ejemplos de campos reconocidos
{{ '{ nombre }' }} {{ '{ apellido }' }} {{ '{ campo 1 }' }} {{ '{ fecha_actual }' }} {{ '{ nombre completo }' }}
Los campos deben escribirse entre llaves dentro del documento de la plantilla.
Formato permitido: .docx , .xlsx
