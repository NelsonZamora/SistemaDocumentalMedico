Administración de Usuarios

Desde esta sección puede crear nuevos usuarios para acceder al sistema médico y administrar sus permisos.

¿Cómo funciona la gestión de usuarios?
Crear usuario
Complete los datos del profesional o administrador que utilizará el sistema.
Asignar permisos
Seleccione si el usuario tendrá acceso como médico o administrador.
Consultar usuarios
Revise la lista de usuarios actualmente registrados en el sistema.

Crear Usuario

Ingrese la información del nuevo usuario del sistema.

Ingrese nombres y apellidos del usuario.
Este correo será utilizado para iniciar sesión.
Recomendado: mínimo 6 caracteres.
Médico: acceso clínico y documentos.
Administrador: acceso completo al sistema.
Auxiliar: acceso clinico y al citas.
Los usuarios creados podrán acceder inmediatamente al sistema utilizando el correo y contraseña registrados.
