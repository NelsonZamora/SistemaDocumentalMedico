Subir Plantilla Médica

Cree plantillas dinámicas para generar documentos automáticamente dentro del sistema.

¿Cómo funciona el procesador de plantillas?
1. Suba el documento Seleccione un archivo estructurado en Word (.docx).
2. Analice el archivo El motor buscará automáticamente las etiquetas dinámicas.
3. Configure campos Mapee si corresponden a texto libre o variables de la BD.
4. Guarde cambios La plantilla quedará disponible para el uso clínico.
Ejemplos de formato reconocido
{{ '{ nombre }' }} {{ '{ apellido }' }} {{ '{ campo_1 }' }} {{ '{ fecha_actual }' }} {{ '{ nombre_completo }' }}
Los marcadores de posición deben escribirse estrictamente entre llaves simples dentro del documento original.
Formatos soportados por el motor de renderizado: .docx o .xlsx
